# Android 3D Fighter (working title)

Established 2026-10-29 by user direction: close the previous 2D project as failed and start again using 3D models.

To play on this Windows machine, double-click [Play Game.cmd](<Play Game.cmd>) in the project folder, or the **Play 3D Fighter** desktop shortcut.

Read [start here](docs/START_HERE.md), [status](docs/STATUS.md), and [assistant instructions](AGENTS.md).

The confirmed direction is a 3D Android game with an isometric camera. Gameplay is still being considered: a Diablo-like ARPG with possible multiplayer PvE/PvP, or an isometric multiplayer PvP-only game. The folder name is temporary, not a commitment to a fighting-game genre or final title.

Godot and GDScript are confirmed for the game. The first [playable movement prototype](game/README.md) has Juggernaut in a landscape isometric arena. The selected extracted Axe, Juggernaut and Shadow Fiend models are documented in the [asset inventory](docs/ASSETS.md); their rights and runtime readiness remain unresolved. The separate [Juggernaut-inspired draft](assets/characters/ember-ronin/README.md) awaits design review. Production version, animation workflow and networking remain undecided.

See [project direction](docs/PROJECT_DIRECTION.md) and [coding standards](docs/CODING_STANDARDS.md) for the brief, open choices and required clean-code practices.

The predecessor is preserved at [android-2d-fighter](../android-2d-fighter/docs/STATUS.md).
